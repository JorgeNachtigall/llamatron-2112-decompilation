# src/platform: host layer (W2)

SDL2 window, audio, input, main loop, asset store and persistent settings for the native
(macOS) and web (Emscripten) builds. The game talks to these APIs only.

## Controls

The game reads the PC keyboard exactly as the original did: every host key is turned into its
PC scan code (set 1, `keymap.c`) and handed to the game's keyboard handler (game86 `1000:e567`).
Both cursor blocks act the same, as on a real keyboard.

| Key | Original meaning |
|-----|------------------|
| Cursor keys / keypad 8 2 4 6 | move (keyboard control, llama.inf `K`) |
| Space | fire |
| P | pause (a random pause picture) |
| while paused: G or O | resume |
| while paused: S | sound on / off |
| while paused: any other key | plays a sample |
| X | abort the wave |
| Q | quit the game |

Joystick control (llama.inf `J`) uses the original's two analogue joysticks; host gamepads stand
in for them (`padmap.c`). Gamepads produce the same scan codes or joystick readings, so the game
sees no difference:

| Gamepad | Keyboard control (`K`) | Joystick control (`J`) |
|---------|------------------------|------------------------|
| left stick / d-pad | cursor keys | joystick 1 |
| A, B | Space (fire) | joystick 1 buttons |
| X, Y | Space (fire) | joystick 2 buttons (one pad only) |
| right stick | Space while pushed | joystick 2 (one pad only: twin-stick aim) |
| second pad, left stick + A/B | (unused) | joystick 2 |
| Start | P (pause) | P (pause) |
| Back / Select | S (sound toggle while paused) | S |

Host-only keys (the game never sees them):

| Key | Native (macOS) | Web |
|-----|----------------|-----|
| F11, Alt+Enter | full screen on / off | page full screen on / off (also a double click) |
| Cmd+F, Ctrl+Cmd+F | full screen on / off | (the browser's own) |
| F10, Cmd+I (macOS) | next scale mode | next scale mode (F10) |

On a Mac keyboard F10 and F11 are media keys unless Fn is held, hence the Cmd shortcuts.
Closing the window, Cmd-Q / Alt-F4 or losing focus are passed to the game as quit / pause
requests; the game decides what they do. Replays (`--replay`, `--keys`) ignore the live
keyboard and gamepads.

## Display

The 320x200 game picture (and the title's 320x400 / 640x350) is shown at 4:3, like on the
1992 monitor, centred with black borders. Scale modes (`platform.h` `PlatScaleMode`, F10 cycles
them, `--scale` / `?scale=` picks the first):

| Mode | Picture |
|------|---------|
| `nearest` (default) | the largest 4:3 rectangle, nearest-neighbour |
| `integer` | whole multiples of each pixel (320x200: 4x5 on 1080p, 5x6 = 1600x1200 is exact 4:3), as close to 4:3 as they get (within 10%; else as `nearest`) |
| `sharp` | the largest 4:3 rectangle: nearest-neighbour to whole multiples, then smoothed down (even pixel sizes without blur at the pixel scale) |

The window is high-DPI aware: on a Retina Mac the picture uses the screen's pixels, not the
window's points (`SDL_WINDOW_ALLOW_HIGHDPI`, `NSHighResolutionCapable` in the app bundle). On
the web the canvas fills the page at 4:3 and its backbuffer is the CSS size times the device
pixel ratio (ctest `web_display_hidpi`).

## Personal-use packages: never distribute

> **Everything below contains assets extracted from your own original Llamatron 2112 files.
> It is for your personal use only and must never be distributed, uploaded, shared or published
> (docs/PLAN.md §0, goal 3).** The repository itself holds no game data; the data only enters
> a build from your local `original/` folder.

### macOS app bundle

```sh
cmake -S . -B build -DLLAMATRON_ORIGINAL_DIR=$PWD/original -DLLAMATRON_MACOS_BUNDLE=ON
cmake --build build            # -> build/Llamatron.app
```

- Packages the executable named by `LLAMATRON_PACKAGE_TARGET` (default `llamatron`, the game:
  title screen, then the game; `llamatron_title` is the M1 title-only app). The target must use embedded assets
  (`LLAMATRON_EMBED_ASSETS=ON`, the default), so the app needs no data folder.
- Generic placeholder icon (generated by `tools/make_icon.py`), `PERSONAL-USE-ONLY.txt` in
  `Contents/Resources`.
- Ad-hoc signed only (`codesign --sign -`) so it runs on this Mac: no Apple account, no
  Developer ID, no notarisation.
- SDL2 is still linked from Homebrew (`brew install sdl2`), so the app runs on a Mac with
  Homebrew's SDL2 installed; it is not a self-contained bundle. **TODO (M7):** copy SDL (with
  the SDL3 library that sdl2-compat loads) into `Contents/Frameworks`, fix the install names and
  re-sign ad hoc.
- Settings are stored in `~/Library/Application Support/llamatron-port/llamatron/llama.inf`.
- Test: `ctest --test-dir build -R macos_app_title`.

### Web folder

```sh
cmake --build build-web --target web-dist   # -> build-web/dist/
```

`index.html` plus the `.js`, `.wasm` and `.data` of `LLAMATRON_PACKAGE_TARGET`, and
`PERSONAL-USE-ONLY.txt`. Serve it from a local web server for yourself only (for example
`python3 -m http.server --bind 127.0.0.1 --directory build-web/dist`); do not put it on a public
server. Settings live in the browser's IndexedDB for that origin.
